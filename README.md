Este es un programa en C++ hecho para registrar las ventas de lunes a domingo del colmado "Don Pepe" y sacar un resumen de la semana usando arreglos, ciclos `for` y condicionales `if`.
## Estudiante
Erick Joel Valdez Jimenez

1 dale doble clic a main.cpp para abrirlo si te pide elegir programa selecciona visual studio
2 arriba en el menu haz clic en build y luego en build solution para ver que todo este bien abajo deberia salir que compilo sin errores
3 presiona ctrl + f5 o dale al boton verde de correr
4 se va a abrir una ventana negra ahi te va pidiendo las ventas de cada dia pones un numero y le das a enter hasta terminar la semana y que te salga el resumen

si no tienes visual studio o estas en otra pc tambien puedes copiar lo que esta en main.cpp pegarlo en una pagina como onlinegdb o programiz y darle a run
